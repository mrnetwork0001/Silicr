# tiny-train

A tiny but real training job for Silicr demos: a character-level bigram language
model (29 × 29 logits) trained with minibatch SGD on a small corpus embedded in
`train.py`. It uses the Python standard library only, so it runs unchanged in
`python:3.12-slim` and with any host `python3` (3.8+).

What it does:

- prints the loss every step, followed by `SILICR_PROGRESS step=<n>` (the runner
  turns those lines into heartbeat progress and strips them from the log)
- writes a checkpoint to `$SILICR_CHECKPOINT_DIR` every 50 steps (keeping the
  newest 3) and resumes from the newest one if present. Resuming is exact: an
  interrupted and resumed run ends with the same weights as an uninterrupted one
- on SIGTERM (what the provider sends when payment stops) it saves a checkpoint
  and partial outputs, then exits with code 143
- at the end, writes `model.json`, `metrics.json` (loss curve, initial and final
  eval loss) and `sample.txt` (text generated by the model) to `$SILICR_OUTPUT_DIR`

The eval loss goes from ln(29) ≈ 3.37 (uniform) to about 2.18 after 600 steps.
The best a bigram model can do on this corpus is about 2.11.

## Run it locally

```bash
cd examples/tiny-train
python3 train.py                                   # ~2.5 minutes (600 steps, 250 ms each)
SILICR_STEPS=100 SILICR_STEP_DELAY_MS=0 python3 train.py   # well under a second
cat output/metrics.json output/sample.txt
```

Without the `SILICR_*_DIR` variables it writes to `./output` and `./checkpoints`.
Delete `checkpoints/` to start from scratch. If you don't, it resumes, and a
finished run just rewrites its outputs.

## Run it the way a provider does

Docker mode (what `@silicr/runner` runs: no network, bundle mounted read-only):

```bash
mkdir -p /tmp/tt-out /tmp/tt-ckpt   # with Colima, use a directory under $HOME instead
docker run --rm --init --network none --read-only --tmpfs /tmp \
  -v "$PWD":/job:ro -w /job \
  -v /tmp/tt-out:/silicr/output -v /tmp/tt-ckpt:/silicr/checkpoints \
  -e SILICR_OUTPUT_DIR=/silicr/output -e SILICR_CHECKPOINT_DIR=/silicr/checkpoints \
  -e SILICR_STEPS=100 -e SILICR_STEP_DELAY_MS=10 \
  python:3.12-slim python train.py
```

Through Silicr, the buyer points `silicr run` at this directory with the command
`python train.py`. The runner packs it, the provider unpacks it, and the outputs
come back as the result bundle.

## Knobs

| Variable | Default | Meaning |
|---|---|---|
| `SILICR_STEPS` | 600 | total training steps |
| `SILICR_STEP_DELAY_MS` | 250 | sleep after each step, so a demo run lasts a few minutes |
| `SILICR_CHECKPOINT_EVERY` | 50 | steps between checkpoints |
| `SILICR_BATCH` | 64 | character pairs per step |
| `SILICR_LR` | 5 | learning rate |
| `SILICR_SEED` | 1337 | seed for minibatches and sampling |
| `SILICR_OUTPUT_DIR` | `./output` | results |
| `SILICR_CHECKPOINT_DIR` | `./checkpoints` | checkpoints |
